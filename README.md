**Aegis32 Dynamic Memory Sentinel (COAL Lab Project)**

This repository contains our Computer Organization and Assembly Language (EL-2003) lab project for FAST-NUCES Karachi (Fall 2026).

The Project is Titled "Aegis32 Dynamic Memory Sentinal"

The Premise is to create a real life accurate model of an antivirus sentinal that uses Dynamic memory and fundamentals of COAL using the irvine32 system to Monitor an attack and log the attacks in an active program

Aegis32 Dynamic Memory Sentinel is a real-time x86 memory integrity monitor built in MASM using the Irvine32 library and the Win32 API. The project models the core mechanics of a user-mode security sentinel—monitoring an active 
32-bit process's executable code pages and dynamically allocated heap values to detect and log unauthorized memory tampering in real time.

This way we can understand the very core that is tied to cyber Security of handling and monitoring systems at the lowest level of programming
